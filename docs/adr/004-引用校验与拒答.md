# ADR 004：生成后逐句校验（数字检查 + Haiku 蕴含判断 + 引用改正），部分支撑的句子改写保留

- 状态：已采纳（作为方法保留；项目场景改为合同风险审查，见 ADR 007）
- 运行：
  - `runs/d4-s20-3a3e17`：20 题小样本；
  - `runs/d4-full-588c85`：v1 策略，174 题；
  - `runs/d4-v2-0cb07c`：v2 策略，复用 v1 那次的原始回答，在 157 题处被预算闸门截停。

## 决定

1. 作答结构：作答拆成 fact 句和 note 句。fact 必须有引用；note 只用于说明边界或建议咨询的部门，不能含数字。另外新增 `unanswered` 字段，用来表达"部分拒答"。
2. 第一层：数字检查。句子里的数字必须出现在支撑它的原文或查表结果里。比较前先统一中文数字、"1万"、千分位的写法；文号、条款号不当作数字。
3. 第二层：Haiku 判断。校验器看本轮检索和查表得到的全部原文，逐句给出 supported / partial / unsupported，并指出真正支撑这句话的原文编号；模型引用挂错的话就自动改正。
4. 降级：
   - unsupported 的句子删掉；
   - partial 的句子按校验器给出的改写保留，只留有依据的部分，改写后再做一次数字检查；
   - 一句 fact 都没留下，整题改为拒答；
   - 校验器自己出错时，保守处理，整题拒答。
5. 评测：用独立的 Sonnet 5.5 当评判（开启服务端 refusal fallback）。一题只调一次，同时评原始回答和校验后的回答。

## 审查后的修改（尚未重跑评测）

- note 句也交给校验器：没有数字的事实性表述（如"研究生也可以申请"）被标成 note 也不能免检；只说明边界、建议咨询部门的 note 句由校验器标 supported 后保留。
- 数字检查只用表格的数据行，表头里的数字不算依据；能识别"两万""十万"这类中文万级数字。
- 由于项目已换场景，这些修改会在合同审查场景的评测里体现，高校场景的 v1、v2 数字保持原样。

## 结果

| 指标 | 原始回答 | v1：部分支撑整句删除（174 题） | v2：部分支撑改写保留（157 题） |
|---|---|---|---|
| 引用准确率（句级） | 91.0% / 90.2%* | 95.6% | 95.2% |
| 幻觉率（作答题中至少有一句无依据） | 28.1% / 31.9%* | 11.9% | 15.6% |
| 答案正确率（要点全对） | 74.3% / 68.0%* | 44.9% | 63.1% |
| 答案正确或部分正确 | — / 95.9%* | 93.4% | 93.4% |
| 误拒率 | 0% | 0.7% | 2.5% |
| 该拒答题：宽口径（拒答或声明边界） | 93.9% / 93.5%* | 93.9% | 93.5% |
| 该拒答题：严格口径（只算整体拒答） | 36.4% / 35.5%* | 36.4% | 35.5% |
| 删除 / 改写 / 改正引用† | — | 删 159 句 / — / 改正 266 处 | 删 29 句 / 改写 123 句 / 改正 329 处 |
| 单题耗时 P50 / P95（作答 + 校验） | — | 12.9s / 19.6s（校验平均 4.4s） | 14.1s / 21.3s（校验平均 5.4s） |

† 改正引用数按旧口径统计（列表比较），只换了顺序、或者原本没引用由校验器补上的，也都算进去了，所以偏高。审查后改为按集合比较，原本没引用的另外计为 `cited_added`。

\* 两组原始回答是同一批，评判分两次跑：v1 那次评 174 题，v2 那次评其中 157 题。原始回答的数字在两次之间相差几个百分点，这就是评判本身的波动（问题日志 P17）。

怎么看这组数字

- 逐句校验在两种策略下都把幻觉率降低了一半以上（28.1% → 11.9%，31.9% → 15.6%），引用准确率都升到 95% 以上。
- 两种策略是取舍关系：v1 删得狠，幻觉最低，但删掉了答案要点，要点全对的比例从 74% 掉到 45%；v2 改写保留，答案正确率只降 5 个百分点，幻觉率比 v1 高约 4 个百分点。线上默认用 v2，理由是答案没用了，"不胡说"也就没有意义。
- 幻觉率 ≤5% 的目标没有达到。剩下的幻觉，主要是 Haiku 判为 supported、Sonnet 却判为不支撑的句子（v1 中有 14 句）。下一步可以在关键数字句上换用更强的校验模型，或者做双模型交叉验证。
- 评判可信度：PRD 要求人工抽检 30 题，这一步没有做（项目已经换场景）。合同审查场景里会按"规则植入风险、自动判分"的方式评测，降低对 LLM 评判的依赖。

## 代价

- 每题多一次 Haiku 调用，约 $0.0006 和 4–5 秒。端到端 P50 因此超过 10 秒的目标（阶段 3 只作答时是 8.0s）。
- Sonnet 评判每题约 $0.012，174 题约 $2，只在评测时使用。
