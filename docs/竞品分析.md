## 2. 观察

1. 小团队缺少低门槛的入口。海外产品都要报价；国内只查到 iTerms 公开了价格，最低一档 6980 元/年。按份付费的只有通义法睿，但它是给开发者的 API，业务人员没法直接用。
2. 依据可追溯没有成为普遍卖点。公开资料里几乎都没有写明会展示法条原文，通义法睿的 API 输出里也没有法条字段。
3. 按公司自己的标准审合同，多数在高档套餐或私有版里。中小企业想用自己的审查规范，门槛高。
4. 国内主流厂商大多是电子签或合同管理平台的附带功能，要先用它的签约平台。独立、即开即用的审查工具较少。
5. 明确写了能选立场的只有 iTerms 和通义法睿。

## 3. 本项目的定位

| 维度 | 本项目 | 说明 |
|---|---|---|
| 依据原文 | 每条意见都能点开法条或公司规范原文，核实不了的标转法务复核 | 针对观察 2；无依据又没标转人工的意见比例 0.8% |
| 公司规范和内部数据 | 导入公司审查规范后按规范红线判断；单价和供应商台账比较 | 针对观察 3；不同公司的规范和数据互相隔离 |
| 立场 | 自动判断，看不出来时先反问 | 针对观察 5 |
| 成本 | 单份模型花费约 1 美分 | 让按份收费在成本上可行 |

差距也很明显：这是一个演示项目，没有真实用户，没有 Word 插件和合同管理流程，覆盖的合同和风险类型也少于商业产品。上面的差异点是否真的有人愿意付费，要靠 [用户试用](用户试用方案.md) 验证。
