# 结构化表（campus 库）

由 `uv run docpilot ingest` 构建为 `data/campus/campus.sqlite`（db_id = `campus`），供 DataPilot 只读查询。

- 每一行都照着已入库的原文手工整理，并带出处：`source_doc_id` 对应 `data/sources.toml`；`source_page` 是 PDF 物理页序号，网页类文件填条款号。
- 公开文件里没有的数字一律不填，也不造示意数据。

| 表 | 内容 |
|---|---|
| `national_aid` | 国家奖助学金标准（财教〔2024〕181 号） |
| `scholarships` | 北师大、中石油的校级奖学金种类、等级、金额、比例 |
| `graduation_rules` | 毕业、结业相关的规则数字（结业学分比例、学制等） |
| `calendar` | 校历关键日期 |

## 已知缺口

- **各专业毕业总学分**：在各专业培养方案里，两本手册都没有收录，所以表里没有；问到时按"未公开/未收录"处理。
- **学院奖学金名额**：两校都只公开了比例，没有公开具体名额。
- **校历**：北师大、中石油的校历是图片，未收录；只有中国矿业大学是文字版 PDF。
- **中石油的国奖、励志金额**：手册第 162、168 页的细则写的是 8000 元、5000 元，但第 174 页的补充说明已按财教〔2024〕181 号改为 10000 元、6000 元。表里记现行金额，出处是第 174 页（订正记录见问题日志 P5）。
